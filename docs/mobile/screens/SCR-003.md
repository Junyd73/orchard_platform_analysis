## 관찰 목적별 입력

목적에 따라 **필요한 입력만** 노출한다.

| 목적 | 입력 |
|------|------|
| 비대 | 가로·세로·둘레·무게 |
| 착색 | 착색도·과피색 |
| 품질 | 당도·경도·메모 |
| 이상과 | 열과·러셋·일소·반점·기형 |
| 기타 | 사진과 자유 메모 |

표시 예: 과경·과고·무게·당도·경도·비대 지수
