## Wizard (4단계)

1. **기본정보** — 관찰일자(오늘 이하)·과실 대상·필지·위치·제목·내용  
2. **사진** — 최대 5장 · HEIC 변환  
3. **열매** — 가로·세로·둘레·무게·형태·과피·결점 YN·과경/꽃받침 등  
4. **완료** — 확정 저장

공통 AppBar + Floating Bottom Action (ODS v1.1+).

## 관찰 목적별 입력 (열매 단계)

목적에 따라 **필요한 입력만** 노출하는 것을 원칙으로 하되, Project A 모바일은 PC와 동일한 측정 폼을 제공한다.

| 목적 | 입력 |
|------|------|
| 비대 | 가로·세로·둘레·무게 |
| 착색 | 착색도·과피색 |
| 품질 | 당도·경도·메모 |
| 이상과 | 열과·러셋·일소·반점·기형 |
| 기타 | 사진과 자유 메모 |

꽃받침(Calyx): `정상` / `숫배` / `기타` (`FY010100`~`300`).

## 추적 (1차 / 2차+)

| 항목 | 규칙 |
|------|------|
| 1차 | 최초 관찰 (`parent` 없음) |
| 2차~ | 추적. **1차 상세**의 「추적관찰」으로만 추가 |
| 제목 | `{기본제목} N차` |
| 2차+ 폼 | 일자·내용만 편집, 제목 읽기 전용 |
| CTA | 2차 이상 상세에서 추적관찰 버튼 **invisible** |

상세·삭제·슬라이드 뷰어는 SCR-004 과실 분기 · Addendum 참조.
