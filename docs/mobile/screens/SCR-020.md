## 1차 통과 범위 (2026-07-22)

### 포함 (동작)

- 메인 대시보드 (Hero KPI · 빠른메뉴 · 재고현황 · 보유현황 · 최근사용)
- 품목 상세 (재고 · 사용 이력 · `work_id` 딥링크)
- **사용 통계** (`/pesticide/stats`) — 일자별 / 농약별(분류 아코디언)
- **농약 사전** (`/pesticide/dict`) — 로컬 `m_pesticide_info` (PSIS 실호출 없음)
- **입고 등록** (`/pesticide/receipts` · 신규/상세 · 재고 반영)
- **재고 관리** (`/pesticide/stock`) — 분류 아코디언 · 수정 · **출고(판매)** · 변동이력
- 대상병해충: 동일 품목명·제조사 형제 `info` 행 집계·검색
- BottomNav: 영농일지·생육관찰 아이콘 갱신 · 「농약관리」+ 약병 아이콘

### 제외 (후속)

- Hero 방제 예정일(+D-day) 실데이터
- 퀵메뉴 **사용 등록** (농약 사용은 **SCR-011**만)
- 발주 추천 · 푸시 알림
- PSIS 실호출·사전 UPSERT (SCR-021)

## 화면 A — 메인 (`/pesticide`)

### Hero

| 영역 | 규칙 |
|------|------|
| KPI | 재고 품목 · 부족(`qty < 10` 명칭 경고색) · 최근 방제일 · 방제 예정(—) |
| 부족 목록 배지 | 메인 보유 목록에는 부족 배지 없음 (명칭 적색만) |

### 빠른메뉴 (1×5)

| 키 | 라벨 | 이동 |
|----|------|------|
| stock | 재고 관리 | `/pesticide/stock` |
| stats | 사용 통계 | `/pesticide/stats` |
| dict | 농약 사전 | `/pesticide/dict` |
| receipt | 입고 등록 | `/pesticide/receipts` |
| low | 부족 확인 | 보유 현황 스크롤 |

### 재고 현황

- 도넛: 분류별 낱개 합 비중
- 레전드: **`{분류} {N}종 {M}개 ({P}%)`** (qty>0 품목만 종류·수량 집계)

### 보유 현황

- 아코디언: 살충제(기본 펼침) · 살균제 · 영양제 · 기타제
- 열: 농약명 · 대상병해충 · 성분 · 재고
- 정렬: 대상병해충 → 재고 많은 순 · qty=0 제외
- 대상병해충: 연결 `info`와 **동일 품목명·제조사** 형제 행의 `pest_map` 합집합

### 최근 사용

- 일자 + 다품목 텍스트 (`노블레스 15개 , …`)

|------|------|

## API (요약)

| 메서드 | 경로 | 용도 |
|--------|------|------|
| GET | `.../pesticide/items` | 목록 + summary |
| GET | `.../pesticide/usage/recent` | 최근 사용 |
| GET | `.../pesticide/items/{id}` | 상세 |
| GET | `.../pesticide/items/{id}/usage` | 사용 이력 |
| GET | `.../pesticide/stats/yearly` | 연간 통계 |
| GET | `.../pesticide/info` · `/info/{id}` | 사전 |
| GET/POST/PUT/DELETE | `.../pesticide/receipts*` | 입고 CRUD · apply |
| PUT/DELETE | `.../pesticide/items/{id}` | 품목 수정·삭제 |
| POST | `.../pesticide/items/{id}/stock-out` | **출고(판매)** |
| GET | `.../pesticide/items/{id}/stock-hist` | 재고·입고 변동 이력 |
