# SCR-010 영농일지 월간

- **상태:** Design Target (시안3 · 결정사항 반영)
- **공통 정책:** `mobile/docs/ODS/ODS_v1.md` (AppBar · BottomNav)
- **PC 대응:** MN17 월간 영농현황
- **구현:** `mobile/src/features/work-log/WorkLogView.vue`
- **API:** `GET .../work-logs/monthly` · 오늘 기상 `GET .../daily/{today}`  
  · **신규 API·DB 스키마 변경 없음**

## 디자인 원칙

| 구분 | 기준 |
|------|------|
| ODS 유지 | AppBar · BottomNav · 카드/버튼/여백 토큰 · 이모지 금지(SVG 아이콘) |
| Hero 예외(승인) | 계절별 과수원 일러스트 + **반투명 녹색 오버레이** (Green Gradient 단독 배경 금지) |
| 캘린더 | 시안2 레이아웃 유지 (아이콘·작업명·선택·범례) |

### 간격 (ODS)

| 항목 | 토큰 |
|------|------|
| 카드·섹션 스택 | `--ods-space-16` |
| 카드 패딩 | `--ods-card-padding` |
| KPI/칩 그리드 | `--ods-space-12` |

## 정보 계층

```text
OdsAppBar
  → Hero(계절 일러스트 · 오버레이 · 오늘 칩)
  → Weather Card(시간별 예보 링크/토스트)
  → 연월 헤더(작업필터 · 오늘) + Calendar
  → 월간 요약(6칸 · 자세히 보기) + 작업일자 분포
  → FAB 등록 → SCR-011
  → OdsBottomNav
```

## Hero

- 에셋: `mobile/src/assets/images/work-log/hero-{spring|summer|autumn|winter}.webp`
- 계절: 3–5 spring · 6–8 summer · 9–11 autumn · 12–2 winter (**오늘 월** 기준)
- 누락 시 ODS Primary **solid** fallback
- 표시: 오늘 날짜 · 인사 · 작업 건수 · 인력 · 경비(당일 셀 집계)

## Weather

- master: 아이콘 · 현재기온(min/max 평균, 없으면 —) · 최고/최저 · 강수 · 습도 · 풍속
- `시간별 예보 >` : 기존 날씨 상세 라우트 있으면 이동, **없으면** 토스트  
  「시간별 예보 화면은 준비 중입니다.」 · 신규 날씨 API/화면 금지

## Calendar (시안2)

- 월 이동 · 요일 · 셀 · 작업 아이콘(SVG) · 작업명 · 오늘 강조 · 범례
- 셀 항목 최대 **3** · 초과 시 `+N`
- 헤더: **[작업필터 ▼] [오늘]**
- 작업필터 BottomSheet(다중, 기본 전체 선택):  
  작업 · 인력 · 경비 · 농약 · 비료 · 기상 · 기타  
  · **클라이언트만** 필터(조회된 monthly days) · 신규 API 없음  
  · 농약·비료는 현재 셀 데이터 없음 → 선택해도 해당 아이콘 미표시

## 월간 요약

- 6칸: 작업 · 투입인력 · 경비 · **농약 —** · **비료 —** · **수확진행률 —**  
  (실데이터 있는 항목만 수치, 임의 계산·하드코딩 금지)
