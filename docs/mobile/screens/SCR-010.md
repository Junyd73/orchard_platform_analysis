- 시안4 UI (흰 페이지 · 계절 Hero · KPI 가로)

- 기상 자동조회 · 캘린더 스와이프(가로=월, 세로=연) · 범례 다중 필터
- Hero「오늘」KPI — 표시 중인 달과 무관하게 유지

### 제외 (Phase 2+ / SCR-011로 이관)
- 일간 인력·경비 CRUD · 전표 · 시간별 예보 · 관찰 딥링크  
  → [`SCR-011.md`](./SCR-011.md) (**UI 확정** · 기능: 월간→일간 → 날씨 → 저장)

## Hero (SCR-010 전용)

### 배경
- 계절별 `hero-{spring|summer|autumn|winter}.png`
  - 봄 3–5 · 여름 6–8 · 가을 9–11 · 겨울 12–2
- 상단은 밝은 사진 유지, **하단 KPI만** 반투명 진녹 밴드
- 에셋 실패 시 ODS primary solid fallback

### 날짜 · 인사
- 날짜: 반투명 어두운 pill + 흰 글씨 (가독성)
- 인사말 **2줄** · 시간대별:

| 시각 | 문구 |
|------|------|
| 12시 이전 | 오늘 하루도 / 힘내세요!!! |
| 12–18시 | 오늘 남은 시간도 / 아자 아자 화이팅!!! |
| 18시 이후 | 오늘 하루도 / 수고 하셨습니다!!! |

### KPI (3열)
- 레이아웃: `[원형 아이콘] 라벨 / 숫자` 가로 · 세로 구분선
- 라벨: `오늘 작업` · `투입 인력` · `오늘 경비` (**한 줄**, nowrap)
- **서브 문구 없음** (진행/예정 · 정규/임시 · 지출 — 삭제)
- **투입 인력:** `N명 · Nh`  
  - 동일인 다작업 = **1명** · `man_hour` **합산**  
  - OWNER/FAMILY 포함(인원·시간). 인건비(금액)는 EMP/TEMP만
- 숫자: 작업·인력·경비 **동일 폰트 크기**
- 금액: **전체 숫자** (`1,250,000원`) — `만원` 축약 금지
- 백만 원 이상: 경비 열 비중↑ · 세 숫자 폰트 동시 축소

### 밀도
- Hero 높이 약 180~188px
- Weather 약 72px · `margin-top: 12px` (겹침 없음)

## Weather · Calendar · Summary

- Weather: 최고/최저 · 메타 (시간별 예보는 홈 이관 · Phase 2+)
- Calendar:
  - **일~토** · 쉬는 날(**토·일·공휴**) 빨강
  - 셀 높이 약 **66px** · 범례 다중 필터 · **오늘** 칩
  - 스와이프: 좌/우=월 · 상/하=연
  - 인력 라인: `N명 · Nh` (일별 고유 인원 + 시간 합)
- Summary: 6칸 · 투입 인력 `N명 · Nh`(월간 고유 인원·시간 합) · 농약/비료 건수 · 수확은 `—`
- Chart: 작업 일자 분포

## ODS 준수

- `OdsAppBar` / `OdsBottomNav` / `OdsFab` / `OdsButton` **컴포넌트 무수정**
- AppBar는 `.content` 안 배치 (v1.1.1) — 좌우 `page-padding` 정렬
- 이모지 금지 · SVG 아이콘
- 화면 전용 CSS는 Hero 톤·KPI 배치에만 제한
- **1차 마감 후 임의 UI 변경 금지** (변경 시 제안·승인)
