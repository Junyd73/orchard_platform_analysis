# SCR-010 영농일지 월간

- **상태:** Draft (MVP 구현 동기화)
- **공통 정책:** `mobile/docs/ODS/ODS_v1.md` (AppBar · BottomNav)
- **PC 대응:** MN17 월간 영농현황 · `WorkLogPage` 월간 스택
- **구현:** `mobile/src/features/work-log/WorkLogView.vue` (월간 기본 진입)
- **API:** `GET /api/v1/farms/{farm_cd}/work-logs/monthly`

## 목적

한 달의 작업 일수·건수·인력·비용을 한눈에 보고, 날짜를 눌러 일간 영농일지로 이동한다.

## 구성

| 영역 | 내용 |
|------|------|
| AppBar | 공통 `OdsAppBar` (Back 없음) |
| 연월 네비 | 이전 / 오늘 / 다음 (미래 월 이동 불가) |
| 요약 KPI | 작업일 수 · 작업 건수 · 인력 건수 · 인건비 합 · 경비·자재 합 |
| 캘린더 | 일자 셀: 작업명 최대 2 · 외 n건 · 이슈 점 · 진행중 강조 |
| BottomNav | 영농일지 활성 |

## UX 규칙

- 미래 날짜 탭 → 일간 이동 없음 + 안내
- 날짜 탭 → `/work-log/{YYYY-MM-DD}` 일간
- 「오늘」→ 당월로 이동 후 오늘 강조

## Phase

- MVP: 조회 전용 (작성은 일간에서)
- 후속: 셀 비용 표시 강화, 관찰 뱃지 병합
