# SCR-002 병해충 생육관찰

- **상태:** Approved (ODS v1.0)
- **원본:** `mobile/docs/ODS/ODS_v1.0.pdf` p.14–15
- **변경:** 금지

## 4단계 입력

1. **기본 정보** — 관찰일·시간·필지·나무 위치·환경·관찰자
2. **병해충 정보** — 병해충 종류·발생 정도·진행상태
3. **사진 및 증상** — 사진 최대 5장·특이사항·관찰 메모
4. **완료** — 입력 요약·저장·AI 분석 선택

## UX 규칙

- 단계별 입력으로 현장 집중도 확보
- 현재 단계는 Orchard Green으로 강조
- 사진: 최대 5장, 촬영·갤러리
- GPS 자동 저장 (실패해도 저장 가능)
- AI는 **저장 후** 사용자 선택 실행
- 긴급 병해충은 방제 일정 확인 안내

## AI 후속 (저장 이후)

1. 사진 선택 (분석용 최대 3장)
2. EXIF·GPS 제거 (서버)
3. 병명 후보·신뢰도
4. 사용자 확정
5. PSIS 공식 농약
6. 보유재고 확인
