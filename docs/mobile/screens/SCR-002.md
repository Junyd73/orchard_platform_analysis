# SCR-002 병해충 생육관찰

- **상태:** Approved (ODS v1.0)
- **원본:** `mobile/docs/ODS/ODS_v1.0.pdf` p.14–15
- **공통 정책:** `mobile/docs/ODS/ODS_v1.md` (ODS v1.1 — 공통 AppBar · Floating Bottom Action)
- **구현:** `ObservationNewView.vue` (기본정보), `ObservationPhotoView.vue` (사진)

## 구현 보완 (ODS v1.1)

- 상단 공통 `OdsAppBar` (농장 맥락). Back은 취소와 동일 경로로 이동.
- 하단 **취소 / 다음·사진** 은 Bottom Nav 위 floating 고정 (**주 액션**).
- **Step** 는 진행 상태만 표현. 현재 단계는 `--ods-color-accent` / `--ods-color-caution` 저채도 Amber. 미완료는 회색.
- **관찰 대상(병해충/과실)** 은 `OdsSegmented` compact 보조 선택. **필수**. 초기 기본 선택 없음.
- **다음** 버튼은 관찰 대상 선택 후에만 활성. 미선택 진행 시 「관찰 대상을 선택해 주세요.」
- 화면 제목(관찰 수정 등)은 AppBar가 아닌 본문 Hero/타이틀 영역.

## 4단계 입력

1. **기본 정보** — 관찰일·시간·필지·나무 위치·환경·관찰자
2. **병해충 정보** — 병해충 종류·발생 정도·진행상태
3. **사진 및 증상** — 사진 최대 5장·특이사항·관찰 메모
4. **완료** — 입력 요약·저장·AI 분석 선택

## UX 규칙

- 단계별 입력으로 현장 집중도 확보
- 현재 Step은 Amber(`--ods-color-accent` / `--ods-color-caution`)로 진행 상태만 강조 (주 액션 Green과 분리)
- 관찰 대상은 필수 선택(초기 미선택). 다음 버튼은 대상 선택 후 활성
- 사진: 최대 5장, 촬영·갤러리
- GPS 자동 저장 (실패해도 저장 가능)
- AI는 **저장 후** 사용자 선택 실행
- 긴급 병해충은 방제 일정 확인 안내

## AI 후속 (저장 이후)

1. 사진 선택 (분석용 최대 3장)
2. EXIF·GPS 제거 (서버)
3. 병명 후보·신뢰도
4. 사용자 확정
5. PSIS 공식 농약
6. 보유재고 확인
