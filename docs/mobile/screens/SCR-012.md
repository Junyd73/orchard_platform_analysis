# SCR-012 알림

- **상태:** In progress · Phase 1 (목록·읽음·딥링크)
- **문서 버전:** 0.2
- **설계 SSOT:** [`docs/NTF-001_notification_system_design.md`](../../../docs/NTF-001_notification_system_design.md)
- **공통 정책:** `mobile/docs/ODS/ODS_v1.md` (Active v1.2.2)
- **진입:** `OdsAppBar` / `WorkLogGreenBar` 우측 **알림** 아이콘 → `/notifications`
- **구현:** `mobile/src/features/notification/NotificationView.vue`

## 목적

농장 단위 알림(작업·관찰 위험·외부 정보)을 조회하고, 읽음 처리 후 관련 화면으로 이동한다.

## 알림 유형 (표시)

NTF-001 `NT01` 공통코드 기준. 목록·필터·배지 색은 유형별 톤.

| 유형 | 라벨 예 | 배지 톤 |
|------|---------|---------|
| NT010100 | 작업 | Primary |
| NT010200 | 관찰 위험·주의 | Caution / Danger |
| NT010300 | AI 미확정 | AI Blue |
| NT010400 | 재관찰 | Accent |
| NT010500 | 기상 | AI Blue |
| NT010600~800 | 농업 정보 | Secondary |
| NT010900 | 시스템 | Gray |

우선순위 `NP01`: 긴급 항목은 좌측 강조 bar 또는 `OdsBadge` variant.

## 화면 구성 (ODS v1.2.2 카드 리스트)

### 1) AppBar

- Back → **이전 화면**

### 2) 상단 컨트롤 바

- 좌측: `전체 알림 N건` (미읽음 있으면 `· 미읽음 M`)
- 우측: 「모두 읽음」 **텍스트 버튼** (블록 버튼 금지)

### 3) 필터 (가로 칩 · Phase 2)

- 전체 · 작업 · 관찰 · 기상 · 농업정보
- **Phase 1 미구현**

### 4) 알림 목록 (홈 알림·리스트 카드 언어)

- Left: 유형 아이콘(위험/AI/작업 KPI)
- Center: `[유형 뱃지]` + 제목(600) + 본문(body-1 / secondary)
- Right: `MM-DD HH:mm` + 딥링크 시 chevron
- 미읽음: soft 강조 + unread dot / 읽음: `opacity: 0.7`
- 카드: white · gray-100 border · radius-button(12) · padding 16
- 탭 → 읽음 처리(`PUT .../read`) 후 `payload.route` 딥링크
  - `observation-detail` + `obs_id` → SCR-004
  - `work-log-daily` + `work_dt` → SCR-011
  - payload 없음 → 읽음만
- AppBar 미읽음 배지: `notificationBadge` 스토어로 목록·AppBar 동기화

### 5) 빈 상태

- `OdsEmptyState`: 「새 알림이 없습니다.」

### 6) BottomNav

- 공통 `OdsBottomNav` 유지

## 딥링크 (`payload_json`)

| route | 대상 |
|------|------|
| `observation-detail` | `/observation/{obs_id}` |
| `observation-list` | `/observation` |
| `work-log-daily` | `/work-log/{work_dt}` |

## DO / DON'T

- **DO:** ODS 토큰·Badge · farm_cd 스코프 · 서버 미읽음 수와 동기화
- **DON'T:** AppBar 중앙에 「알림」 타이틀 · Push 권한 팝업 Phase 1 · Chip Filter Phase 1

## API (NTF-001 §7)

- `GET /api/v1/farms/{farm_cd}/notifications`
- `GET .../summary` — AppBar 배지
- `PUT .../{noti_id}/read` · `PUT .../read-all`
