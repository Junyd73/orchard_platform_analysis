# SCR-012 알림

- **상태:** Draft · 설계 (NTF-001 연동)
- **문서 버전:** 0.1
- **설계 SSOT:** [`docs/NTF-001_notification_system_design.md`](../../../docs/NTF-001_notification_system_design.md)
- **공통 정책:** `mobile/docs/ODS/ODS_v1.md` (Active v1.2.2)
- **진입:** `OdsAppBar` 우측 **알림** 아이콘 (현재 「준비 중」 토스트 → 본 화면)
- **구현 예정:** `mobile/src/features/notification/NotificationView.vue`

## 목적

농장 단위 알림(작업·관찰 위험·외부 정보)을 조회하고, 읽음 처리 후 관련 화면으로 이동한다.

## 알림 유형 (표시)

NTF-001 `NT01` 공통코드 기준. 목록·필터·배지 색은 유형별 톤.

| 유형 | 라벨 예 | 배지 톤 |
|------|---------|---------|
| NT010100 | 작업 | Primary |
| NT010200 | 관찰 위험·주의 | Caution / Danger |
| NT010300 | AI 미확정 | AI Blue |
| NT010400 | 재관찰 | Accent |
| NT010500 | 기상 | AI Blue |
| NT010600~800 | 농업 정보 | Secondary |
| NT010900 | 시스템 | Gray |

우선순위 `NP01`: 긴급 항목은 좌측 강조 bar 또는 `OdsBadge` variant.

## 화면 구성

### 1) AppBar

- Back → **이전 화면** (호출 화면명 AppBar 중앙 타이틀 금지 — ODS §3)
- 우측: 「전체 읽음」(텍스트 또는 아이콘)

### 2) 요약 (선택 · Phase 1 간략)

- 미읽음 N건 · 긴급 M건 (한 줄)

### 3) 필터 (가로 칩 · Phase 2)

- 전체 · 작업 · 관찰 · 기상 · 농업정보
- 기본: **전체**

### 4) 알림 목록

- `OdsCard` 또는 리스트 행
- 각 행:
  - 유형 배지 + 우선순위(긴급만)
  - **제목** (1줄 말줄임)
  - **본문 요약** (2줄 max, secondary color)
  - **발생 시각** (상대 또는 MM/DD HH:mm)
  - 미읽음: 좌측 dot 또는 배경 `--ods-color-primary-soft`
- 탭 → 상세 또는 **payload 딥링크** (관찰 상세·영농일지 일간 등)
- 스와이프 → 숨김(dismiss) Phase 3

### 5) 빈 상태

- `OdsEmptyState`: 「새 알림이 없습니다.」
- **섹션 숨김 금지** — SCR-001 빈 구간 정책과 동일

### 6) BottomNav

- 호출 전 화면과 동일하게 유지 (관찰 플로우면 각 화면 BottomNav)

## 딥링크 (`payload_json`)

| route | 대상 |
|-------|------|
| `observation-detail` | `/observation/{obs_id}` |
| `observation-list` | `/observation` + query |
| `work-log-daily` | `/work-log/{work_dt}` |
| `external-link` | in-app WebView 또는 시스템 브라우저 (외부 RSS) |

## DO / DON'T

- **DO:** ODS 토큰·Badge · farm_cd 스코프 · 서버 미읽음 수와 동기화
- **DON'T:** AppBar 중앙에 「알림」 타이틀 · Push 권한 팝업 Phase 1 · 알림 본문에 API 키·내부 URL

## API (NTF-001 §7)

- `GET /api/v1/farms/{farm_cd}/notifications`
- `GET .../summary` — AppBar 배지
- `PUT .../{noti_id}/read` · `PUT .../read-all`

## Phase

| Phase | 범위 |
|-------|------|
| 1 | 목록·읽음·관찰/재관찰 딥링크 |
| 2 | 필터·기상·RSS · 배지 |
| 3 | dismiss · 설정(유형 on/off) |
