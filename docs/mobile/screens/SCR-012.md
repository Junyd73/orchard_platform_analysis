## 목적

농장 단위 알림(작업·생육관찰·기상·시세·병해충 예보)을 조회하고, 읽음 처리 후 **필요할 때만** 관련 화면으로 이동한다.

## 알림 유형 · ODS 그룹 시각화

유형 뱃지 글자는 **공백 제거 후 2글자×N줄**(예: `가락시세` → 가락/시세, `생육관찰` → 생육/관찰).

| 유형 | 표시 라벨 | 그룹 | 좌측 보더·뱃지 색 | 큰 아이콘(ODS SVG) |
|------|-----------|------|-------------------|-------------------|
| NT011000 | 가락 시세 | market | primary(초록) | `icon-kpi-fruit` |
| NT010500 | 기상 | weather | ai(하늘) | `wx-sunny` |
| NT010600 | 농촌진흥청 | rda | caution(호박) | `icon-kpi-warn` |
| NT010700 | 기술센터 | rda | caution | 동일 |
| NT010100~400, NT010900 | 작업·생육관찰·시스템 등 | system | stone(회색) | `icon-clipboard` |

- **NT010200** 표시명: **생육관찰** (구: 관찰 위험·주의)
- 큰 아이콘만 사용(뱃지 안 작은 아이콘 없음). 아이콘 웰은 그룹색 **반투명** 배경.
- 긴급(`NP010100`)은 뱃지 tone `danger` 유지.

## 화면 구성

### 1) AppBar

- Back → 이전 화면
- 농장명: `farm.farm_nm` (코드 `OR001` 폴백 금지 우선)

### 2) 상단 컨트롤 바

- 좌측: `전체 알림 N건` (미읽음 있으면 `· 미읽음 M`)
- 우측: 「모두 읽음」 텍스트 버튼

### 3) 알림 목록

- Left: 그룹 아이콘 웰 + **좌측 4px 포인트 보더**
- Center: 유형 뱃지(2×N) + 제목 + 본문(2줄 clamp)
- Right: `MM-DD HH:mm` + chevron(딥링크 있을 때만 강조)
- 탭 → 읽음 + **바텀시트 모달** (즉시 navigate 없음)

### 4) 상세 모달 (`NotificationDetailModal`)

공통:

- 헤더: 유형 뱃지 · 시각 · **`출처: {payload.source_org}`**
- 확인 버튼
- **`해당 화면으로 이동`**: `payload.route`(또는 호환 키) **있을 때만**

유형별 본문 블록:

| 유형 | 모달 추가 UI |
|------|----------------|
| 기상 daily | 방제작업여건(좋음/주의/나쁨) · 오늘/내일 기상요약 |
| 시세 daily | 법인별 출하 표 |
| 시세 signal | 출하여건·가격·추세 본문 + **최고가/평균가 5영업일 흐름표**(당일 증감% 빨강↑/파랑↓) |
| 병해충 브리핑 | **기관별 안내** (`농촌진흥청 : …` / `기술지원센터 : …`) · **딥링크 없음** |
| 생육관찰(주의·위험) | **추천 방제 및 대응 가이드** 강조 박스 · 관찰 상세 딥링크 |

## 딥링크 (`payload`)

| route | 대상 | 비고 |
|------|------|------|
| `observation-detail` | `/observation/{obsId}` | 생육관찰 방제 가이드 |
| `work-log-daily` | `/work-log/{workDt}` | 미완료 작업 |
| (없음) | — | 병해충 브리핑·기상 요약 등 정보성 |

## payload 주요 키

| 키 | 용도 |
|----|------|
| `source_org` | 공식 출처 문구(모달 헤더) |
| `weather` / `weather_tomorrow` / `spray` | 기상 |
| `market` / `view:signal` / `flow` | 시세·시그널 |
| `agency_lines` / `view:pest_briefing` | 병해충 기관별 안내 |
| `spray_guide` | 관찰 방제 가이드 |

## DO / DON'T

- **DO:** ODS SVG·tokens · `source_org` · farm_cd 스코프 · 그룹 보더로 0.1초 구별
- **DON'T:** lucide/Tailwind 신규 도입 · 정보성 알림에 불필요 딥링크 · AppBar에 「알림」 타이틀

## API

- `GET /api/v1/farms/{farm_cd}/notifications`
- `GET .../summary`
- `PUT .../{noti_id}/read` · `PUT .../read-all`
