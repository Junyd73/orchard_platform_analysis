## 기능 구현 순서

| 순번 | 기능 | 상태 | 요지 |
|------|------|------|------|
| **1** | 월간 → 일간 연결 | **완료** | 캘린더/FAB 진입 · 당일 작업 API 로드 · Back 시 월 유지 |
| **2** | 일간 날씨 | **완료** | GET daily(DB·캐시) → 없으면 `weather/fetch` |
| **3** | 입력 → 임시저장 → 저장 | **완료**(작업행 MVP) | 작업내용 선택·임시저장·저장하기·삭제. 인력·경비·농약·사진은 후속 |
| **4** | 인력·경비·농약 + 회계/재고 | **완료** | Core 공통. 저장하기=장부+농약 확정. 농약 수정=저장 시 replace 단일 TX |

### 저장 정책 (PC·Mobile 동일)

- **공통 Service:** `core/work_log_integrated_save_service.py` (PyQt·FastAPI 동일 호출)
- **임시 저장:** 작업행만 (`PUT .../works` → `save_work_log_basic`) — 장부·재고 미반영
- **저장하기:** `PUT .../integrated` → `save_integrated` — 인력/경비 Ledger + 농약 확정
- **경비:** `pay_status='Y'`만 Ledger · Fingerprint 역분개 유지
- **농약:** 초안 없음 · 저장=확정 · 취소=`cancel_yn='Y'`(미확정과 구분)
- **농약 수정:** 「수정」진입만으로 재고 복원 안 함 · 저장 시 replace 단일 TX
- **농약 취소:** `use_id` 단위 · 작업 전건은 `cancel-all`

## API (참조)

| 메서드 | 경로 | 용도 |
|--------|------|------|
| GET | `/farms/{farm}/work-logs/daily/{work_dt}` | 마스터 + 작업 + 인력/경비/농약 |
| POST | `.../daily/{work_dt}/weather/fetch` | 외부 기상 → 캐시 |
| PUT | `.../daily/{work_dt}/master` | 마스터 저장 |
| PUT | `.../daily/{work_dt}/works` | 작업행 임시 저장(작업-only) |
| PUT | `.../daily/{work_dt}/integrated` | 통합 저장(장부·농약 확정) |
| POST | `.../pesticide/cancel` | 농약 사용 취소(`use_id`) |
| POST | `.../pesticide/cancel-all` | 작업 연결 농약 전건 취소 |
| POST | `.../pesticide/replace` | 확정 농약 수정 저장(단일 TX) |
| DELETE | `.../works/{work_id}` | 작업 삭제 |

상세: [`../api/README.md`](../api/README.md)
