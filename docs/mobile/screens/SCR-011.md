# SCR-011 영농일지 일간

- **상태:** Draft (MVP 구현 동기화)
- **공통 정책:** `mobile/docs/ODS/ODS_v1.md`
- **PC 대응:** MN01 영농일지 일간 · `WorkLogPage` 일간 스택
- **구현:** `mobile/src/features/work-log/WorkLogDailyView.vue`
- **API:** `GET/PUT .../work-logs/daily/{work_dt}` · `PUT .../works` · `DELETE .../works/{work_id}`

## 목적

하루의 기상·이슈·작업 목록을 현장에서 조회·저장한다.  
MVP에서는 **인력·경비·농약·전표 제외**.

## 구성

| 영역 | 내용 |
|------|------|
| AppBar | 공통 + Back → 월간 |
| 일자 | `YYYY-MM-DD` (미래일 저장 불가) |
| 기상 | 날씨코드·기온·강수·습도 등 (수동 입력, 가져오기는 Phase 2) |
| 이슈 | `work_rmk` 텍스트 |
| 작업 목록 | 유형(WK)·장소·시작/종료·상태(WO01)·비고 · 추가/삭제 |
| Floating | 저장 |
| BottomNav | 영농일지 |

## 저장 규칙

- 마스터(기상·이슈) + 작업행 일괄 저장
- `work_id` = `YYYYMMDD-NN` (PC와 동일)
- 화면에 없는 작업행은 삭제(자식 인력/경비 있으면 삭제 거부)

## Phase 2+

- 작업별 인력·경비
- 날씨 가져오기
- 전표·농약 확정
