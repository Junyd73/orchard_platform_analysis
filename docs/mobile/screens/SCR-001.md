## 목적

최근 7일 관찰·AI·위험 상태를 한눈에 보고, 필지·기간·검색으로 관찰을 조회하며, FAB로 새 관찰·초안 이어쓰기를 시작한다.

## 확정 정책 (2026-07-19 ~ 07-20)

| 항목 | 결정 |
|------|------|
| 날씨 | **표시하지 않음** (영농일지에만) |
| 초안(작성 중) | 메인 목록 **없음** · **FAB**에서 「이어서 / 새 관찰」 |
| 빈 구간 | 숨기지 않음 · **안내 문구** 표시 |
| 주간 캘린더 날짜 | 클릭 시 하단 관찰조회에 **그날** 목록 (`date_from`=`date_to`) |
| Hero KPI 집계 | **최근 7일** 목록 클라이언트 집계 (`observationHomeWeek.ts`). summary API는 홈 KPI에 사용하지 않음 |
| 목록 기본 제목 | **최근 7일 관찰 내역** (기본 기간일 때). 단일일·다른 기간은 `관찰내역(MM/DD ~ MM/DD)` |
| 목록 카드 배지 | **분석 상태** + **위험도** 동시 표시 (예: 분석 완료 / 위험). `CONFIRMED`도 목록에서는 「분석 완료」 |
| AI 분석(묶음) | 상위 타이틀 **AI 분석** 아래 위험 감지·최근 분석(7일) 소제목 + 각 내용 판넬 |
| AI 위험 카드 | 최근 7일 **주의·위험**(`OS010300`/`OS010400`) · 가로 슬라이드 · 탭 → 상세 |
| AI 위험 카드 구성 | **1줄 병해충명**(`ai_pest_nm`) · **2줄** 위험도 뱃지(박스) + 발견일(기본 텍스트색). 슬래시 없음 |
| 최근 AI 분석 | 최근 7일 AI 관여 건 실데이터 · 판넬 안 가로 스크롤 · 탭 → 상세 · 「전체 보기」→ 7일 목록 스크롤 |

## DO / DON’T

- **DO:** 사진 중심 · 카드 중심 · 한 손 · 공통 AppBar/BottomNav · 빈 상태 안내 · 최근 7일 실데이터
- **DON’T:** 메인에 날씨 · 메인에 초안 리스트 · 표 형식 · AppBar를 content 밖 배치 · **빈 AI 구간 숨김** · 위험 카드에 관찰제목을 병해충명 대신 사용 · 날짜를 위험색으로 표시
