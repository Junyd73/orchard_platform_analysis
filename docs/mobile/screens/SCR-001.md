오늘 관찰 상태를 한눈에 보고, 필지·기간·검색으로 관찰을 조회하며, FAB로 새 관찰·초안 이어쓰기를 시작한다.

## 확정 정책 (2026-07-19)

| 항목 | 결정 |
|------|------|
| 날씨 | **표시하지 않음** (영농일지에만) |
| 초안(작성 중) | 메인 목록 **없음** · **FAB**에서 「이어서 / 새 관찰」 |
| 빈 구간 | 숨기지 않음 · **안내 문구** 표시 |
| 주간 캘린더 날짜 | Phase 3 · 클릭 시 하단 관찰조회로 그날 목록 (예정) |

| Phase | 범위 | 상태 |
|-------|------|------|
| **1** | 히어로(사진) · KPI 4 · 관찰 조회 · FAB 초안 | **완료** |

## DO / DON’T

- **DO:** 사진 중심 · 카드 중심 · 한 손 · 공통 AppBar/BottomNav · 빈 상태 안내
- **DON’T:** 메인에 날씨 · 메인에 초안 리스트 · 표 형식 · AppBar를 content 밖 배치 · **빈 AI 구간 숨김**
