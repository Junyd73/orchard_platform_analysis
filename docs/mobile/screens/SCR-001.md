# SCR-001 생육관찰 메인

- **상태:** Approved (ODS v1.0 시안) + **ODS v1.1.1** 공통 셸 적용
- **원본:** `mobile/docs/ODS/ODS_v1.0.pdf` p.12–13
- **공통 정책:** `mobile/docs/ODS/ODS_v1.md`
- **구현:** `mobile/src/features/observation/ObservationView.vue`

## 목적

최근 관찰을 확인하고, AI 미분석·재관찰 상태를 파악하며, 새로운 관찰을 빠르게 시작한다.

## 구성

| 영역 | 내용 |
|------|------|
| 공통 AppBar | `OdsAppBar` (`.content` 안, Back 없음) |
| Hero Header | 따뜻한 메시지, 오늘 날짜·날씨 |
| 요약 카드 | 오늘 관찰, 위험, 과실 관찰, AI 대기 |
| 작성 중(Draft) | 이어쓰기·취소 패널 |
| 필터 | 전체 필지·정렬·검색 |
| 관찰 카드 | 대표사진, 유형, 제목, 위치, 상태, 날짜 |
| FAB | + 관찰하기 |
| Bottom Navigation | 홈 · 생육관찰 · 영농일지 · 주문관리 · 내정보 |

## DO / DON’T

- **DO:** 사진 중심 · 카드 중심 · 큰 버튼 · 한 손 사용 · 공통 AppBar/BottomNav
- **DON’T:** 표 형식 · 작은 버튼 남발 · 이중 스크롤 · 회색 남용 · AppBar를 content 밖 배치
