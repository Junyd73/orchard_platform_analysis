## 화면 규칙 (SCR-004 전용)

### 등록 플로우 연계 (수정 진입)

상세에서 수정으로 들어갈 때:

- 병해충: SCR-002 Wizard 규칙
- 과실: SCR-003 Wizard (기본→사진→열매→완료)
- Step 현재 단계는 Amber(`--ods-color-accent` / `--ods-color-caution`)
- 관찰 대상은 필수. 신규 초기 기본 선택 없음

### 사진 가로 스와이프 (Horizontal Media Strip)

- 최대 등록 수 **5장** 유지. 데이터는 전부 DOM에 렌더한다(처음 3장만 그리지 않음).
- 가로 스크롤 + `scroll-snap`. 일반 모바일에서 약 **2.7~3장** 노출(다음 장 일부 보임).
- 빈 슬롯 카드·강제 중앙 정렬 금지.
- 간격은 ODS spacing token. 스크롤바는 숨김.
- 클릭 → 기존 PhotoViewer. 삭제·대표·순서 로직 변경 없음.
- 수량 표시: `n / 5 장` (기존 count).
- HEIC: 업로드 전 변환 (ODS v1.1.1).

### 사진 추가 버튼

| 이전 | 변경 |
|------|------|
| 카메라 촬영 | 카메라 |
| 갤러리 선택 | 갤러리 |

- 시각적 높이·패딩·텍스트를 한 단계 축소(보조 액션). 터치 영역 ≥ 44×44px.
- 아이콘 유지. 5장 가득 시 기존 비활성화 정책 유지.

### 과실 추적 · 삭제 (v1.2)

- 타임라인 사진 → `FruitTrackSlideViewer` (전체화면 스와이프)
- 타임라인 본문 → 해당 차수 상세
- **추적관찰**: 1차 + COMPLETED 만 표시. 2차+ invisible
- **1차 삭제**: 2차 이상 일괄 삭제 경고 후 확인 (`ObservationDeleteDialog` relatedTrackCount)
- **2차+ 삭제**: 해당 건만 삭제 가능
