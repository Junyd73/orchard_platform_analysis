## 1. 목적

생육관찰 메인 Hero가 **매번 동일한 이미지만** 노출되지 않도록 한다.

| 유지 | 변경 가능 |
|------|-----------|
| 레이아웃(골격) | Hero 사진 |
| 영농일지와 동일 디자인 언어 | AI 포인트(우측 강조) |
| KPI 영역 높이·배치 골격 | 계절 컬러 톤 |
| | 날씨 효과(사진) |

**레이아웃은 절대 변경하지 않는다.**

---

## 2. Hero 레이아웃 (고정)

영농일지(SCR-010)와 **동일 골격**.

```
────────────────────────
날짜
오늘도 생육을
꼼꼼히 살펴보세요

AI 안내문

                         Hero Image
────────────────────────
병해충 | 과실 | AI분석 | 위험분석
────────────────────────
```

| 영역 | 규칙 |
|------|------|
| 날짜 | 좌측 상단 칩 |
| 카피 | `오늘도 생육을` / `꼼꼼히 살펴보세요` (2줄) |
| AI 안내문 | 좌측 카피 하단 — **문구만**, 레이아웃 위치 고정 |
| Hero Image | **우측** — 사진·AI 포인트만 교체 |
| KPI | Hero **하단** 4칸 고정 · 영농일지와 **동일 높이** 유지 |

---

## 3. 계절 테마 (4종)

월 기준으로 계절을 정한다. (영농일지 `heroSeasonForMonth`와 동일: 3–5 봄 / 6–8 여름 / 9–11 가을 / 12–2 겨울)

| ID | 계절 | 모티프 | 컬러 톤 |
|----|------|--------|---------|
| `spring` | Spring | 새순 · 꽃 · 인공수분 | **연두색** |
| `summer` | Summer | 잎 · 어린과실 · AI 스캔 | **진한 녹색** |
| `autumn` | Autumn | 익은 신고배 · 수확 · 품질 분석 | **골드** |
| `winter` | Winter | 전정 · 겨울 과수원 · 관리 | **블루그레이** |

- 계절은 **배경 톤·오버레이·액센트**에 반영한다.
- 사진 자산은 계절 폴더/접두사로 관리한다. (예: `hero-{season}-…`)

---

## 4. AI 관찰 테마 (6종)

**Hero 오른쪽 이미지만** 변경한다. (좌측 텍스트·KPI 골격 불변)

| ID | 테마 | 표현 |
|----|------|------|
| `leaf` | 잎 분석 | AI가 잎을 스캔 |
| `fruit` | 과실 분석 | 배를 분석 |
| `pest` | 병해충 분석 | 해충 탐지 |
| `shoot` | 새순 분석 | 신초 생육 |
| `bloom` | 꽃 분석 | 개화 상태 |
| `bag` | 봉지 상태 | 봉지 손상 확인 |

---

## 5. 날씨 효과 (4종)

**사진만** 변경한다. (레이아웃·KPI 불변)

| ID | 효과 |
|----|------|
| `sunny` | 맑음 |
| `cloudy` | 흐림 |
| `rain` | 비 |
| `fog` | 안개 |

실제 기상 API와 연동 시에는 `as_of` 시각 기준 날씨 코드를 매핑하고, 미연동·뼈대 단계에서는 랜덤/시즌 기본값을 쓸 수 있다.

| 순 | 라벨 | 비고 |
|----|------|------|
| 1 | 병해충 관찰 | |
| 2 | 과실 관찰 | |
| 3 | AI 분석 | |
| 4 | 위험 분석 | |

> **2026-07-19:** 「오늘 관찰」 삭제 → **4칸**. (`today_count` 집계 필드는 API에 유지)

## 7. 랜덤(조합) 규칙

### 7.1 불변

- Hero **레이아웃** (섹션 2)
- KPI **4칸 구성·높이**

### 7.2 가변

| 축 | 종류 수 | 변경 대상 |
|----|---------|-----------|
| 계절 | 4 | 컬러 톤 + (가능하면) 계절 사진 베이스 |
| AI 테마 | 6 | 우측 Hero 이미지·AI 포인트 |
| 날씨 | 4 | 사진(날씨 효과) |

### 7.3 조합 수

\[
4 \times 6 \times 4 = \mathbf{96}
\]

**총 96가지** Hero 조합이 가능하다.

### 7.4 선정 정책 (권장)

| 항목 | 권장 |
|------|------|
| 계절 | **달력 월**로 고정 (랜덤 제외) |
| AI 테마 | 세션/일 단위 랜덤 또는 가중(최근 관찰 유형) |
| 날씨 | 실측 기상 우선 · 없으면 랜덤/기본(`sunny`) |
| 재진입 | 같은 날·같은 농장은 동일 시드 → **깜빡임 방지** (선택) |

## 8. DO / DON’T

**DO**

- 영농일지와 같은 카드형 Hero·플랫 KPI 높이감
- 우측 이미지만 교체해 다양성 확보
- 자산·상수로 테마 ID 관리 (하드코딩 금지)

**DON’T**

- 좌측 카피·날짜·KPI 골격 이동/삭제
- KPI를 4칸으로 되돌리기 (본 문서 확정 후)
- 문서형(클립보드) 일러스트 (ODS AI 일러스트 금지 규칙 준수)
