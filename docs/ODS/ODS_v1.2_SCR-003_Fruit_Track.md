# Orchard Design System v1.2 Addendum

- 상태: **Approved (구현 동기화)**

- 상위 기준: `ODS_v1.md` (ODS v1.2)
- 시각 원본: `ODS_v1.0.pdf` p.16–17 (PDF 자체는 수정하지 않음)
- 관련 SCR: `SCR-003.md`, `SCR-004.md`

## 1. 목적

과실(열매) 관찰을 1차 등록부터 N차 추적까지 한 흐름으로 기록하고,  
상세에서 차수·측정·사진을 비교·확인할 수 있게 한다.

Project A에서 **과실 AI 예측은 제공하지 않는다.** 상세에서 AI·스마트 방제 카드를 숨긴다.

## 2. 차수 모델

| 차수 | 의미 | 데이터 |
|------|------|--------|
| **1차** | 최초 관찰 | `parent_obs_id` 없음 (root) |
| **2차** | 첫 추적 | 「추적관찰」로 생성 (parent = 1차 root) |
| **3차~** | 이후 추적 | N차 상세의 「추적관찰」로 추가. **parent 는 항상 1차 root** |

- 타임라인·요약: `1차` · `2차` · … 뱃지/문구
- 신규 추적 제목: `{1차 기본제목} N차` (N = 현재 건수 + 1)
- 구형 제목 접미 `N차추적` 은 생성·표시 시 정규화하여 `N차` 체계로 맞춤

## 3. Wizard (과실 등록)

1. **기본정보** — 관찰일자(오늘 이하)·대상(과실)·필지·위치·제목·내용  
2. **사진** — 최대 5장 (HEIC는 업로드 전 변환)  
3. **열매** — 측정 입력 (`ObservationFruitMeasureView` / `FruitMeasureForm`)  
4. **완료** — 확정 저장

병해충 Wizard(SCR-002)와 Step 구성이 다르다. 과실 선택 시 본 Addendum·SCR-003을 따른다.

### 추적 관찰 폼 (2차+)

- 편집 가능: **관찰일자**, **관찰 내용**
- 제목: 읽기 전용 (`{기본} N차`)
- 필지·위치·대상: 1차 승계(읽기/고정)

## 4. 상세 (SCR-004 과실 분기)

카드 순서:

1. AppBar (+ Back)
2. Hero
3. 관찰 내용
4. **사진** (`PhotoPanel`) — **현재 차수** 사진. 1차·2차·N차 모두 표시
5. **과실 추적** 카드
   - 추적 요약 (표본 위치 · `1~N차 · 총 N건` · 치수 요약)
   - 타임라인 (차수 뱃지 · 치수 · Δ)
   - **추적관찰** 버튼: **모든 차수 상세**에 표시. 클릭 시 항상 **1차(root)** 기준으로 다음 차수 등록. 1차 미완료 시에만 비활성
6. 관리정보
7. Floating 수정·삭제 + BottomNav

표시하지 않음: AI 분석 카드, 스마트 방제 가이드 카드.

### 타임라인 인터랙션

| 제스처 | 동작 |
|--------|------|
| 썸네일/사진 | 전체화면 **슬라이드 뷰어** (차수 간 스와이프) |
| 본문(일자·제목·치수) | 해당 `obs_id` **상세**로 이동 (수정·삭제) |

## 5. 삭제

| 대상 | 동작 |
|------|------|
| **1차** | 동일 `root_obs_id` 의 **2차 이상**도 함께 삭제. 확인 다이얼로그에 「2차 이상 N건 함께 삭제」 경고 |
| **2차 이상** | **해당 건만** 삭제. 1차·다른 차수는 유지 |

삭제 권한·복구 불가 안내는 기존 SCR-004/삭제 정책을 따른다.

## 7. 금지

- 추적관찰 parent 를 2차+ obs_id 로 직접 연결 (항상 **1차 root**)
- 과실 상세에 AI/PSIS 카드 노출
- 차수 명명을 「원 관찰 / N차추적」으로 되돌리기
- ODS PDF 임의 수정 · 새 Color/Card 토큰 남발
