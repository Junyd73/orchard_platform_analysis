# Orchard Design System v1.0.1 Addendum

## SCR-004 생육관찰 상세조회

- 상태: **Approved**
- 승인일: 2026-07-17
- 상위 기준: `ODS_v1.md` (Orchard Design System), 시각 원본 `ODS_v1.0.pdf`
- 공식 참고 이미지: `SCR-004_approved_reference.png`

## 1. 목적

사용자가 관찰의 핵심 상태, 내용, 사진, AI, PSIS 및 관리정보를 한 화면에서 빠르게 확인하고 수정 또는 삭제할 수 있도록 한다.

SCR-004는 조회 중심 화면이며, SCR-001~003의 디자인 언어와 ODS 공통 컴포넌트를 그대로 계승한다.

## 2. 최상위 원칙

1. ODS v1(`ODS_v1.md`)을 최상위 기준으로 적용한다.
2. 승인된 참고 이미지의 배치, 정보 계층, 색상, 간격, 카드 구조를 임의로 변경하지 않는다.
3. 새 버튼, 카드, 배지, 색상 토큰을 임의 생성하지 않는다.
4. 불가피한 변경은 구현 전에 제안하고 승인을 받는다.
5. 기능 구현을 이유로 승인된 시각 구조를 축소하거나 단순화하지 않는다.

## 3. 화면 구조

### 3.1 Top App Bar

> ODS v1.1+ 공통 정책: `ODS_v1.md` — Sticky AppBar · `.content` 내부 배치(v1.1.1)

- 공통 `OdsAppBar` 사용
- 좌측 농장명, 우측 알림/설정
- 화면명·햄버거·Emoji 사용 금지
- **상세 화면 Back 허용** → 관찰 목록(`observation`)으로 `router.push` (ODS v1.1 뒤로가기 정책)
- Camera / Viewer / Modal / 슬라이드 뷰어는 각 오버레이 Back 유지

### 3.2 Hero Card

표시 순서:

1. 관찰 유형 및 부위
2. 관찰 제목
3. 상태 배지
4. AI 상태 배지
5. 관찰일시, 작성자, 수정시간
6. 우측 일러스트레이션

규칙:

- 관찰번호를 주 제목으로 사용하지 않는다.
- 관찰 제목을 화면 내 가장 강한 텍스트 계층으로 표시한다.
- 상태와 AI 상태는 색상과 문구를 함께 사용한다.
- 필지, 구역, 열, 나무번호 데이터가 존재하면 제목 아래 보조정보로 표시한다.

### 3.3 관찰 내용 Card

- 카드 제목: `관찰 내용`
- 관찰 메모와 핵심 입력정보 표시
- 환경정보가 존재하면 ODS 배지 또는 간결한 메타정보로 표시
- 빈 값은 불필요한 행으로 노출하지 않는다.

### 3.4 사진 Card

- 대표사진을 우선 표시
- 최대 5장
- 사진 수 표시
- 썸네일 또는 슬롯 구조
- 카메라 촬영 및 갤러리 선택 제공
- 사진 클릭 시 전체화면 Viewer
- 대표 지정, 추가, 삭제, 순서 변경 지원
- 사진 관리 진입을 위한 별도 상단 버튼을 추가하지 않는다.
- 등록 가능한 빈 슬롯은 승인 시안처럼 명확히 표시한다.
- **ODS v1.2:** 과실 추적의 **모든 차수** 상세에서 해당 차수 사진을 동일 카드로 표시한다.

### 3.4b 과실 추적 Card (ODS v1.2)

과실(`OB010200`) 상세에만 표시. AI·스마트 방제 카드는 숨긴다.

- 요약 · 타임라인(`N차` 뱃지) · 추적관찰 CTA(1차만)
- 상세 규칙: `ODS_v1.2_SCR-003_Fruit_Track.md`, `SCR-004.md`

### 3.5 AI 분석 Card

> 과실 상세에서는 본 카드를 표시하지 않는다 (v1.2).

상태:

- AI 대기
- 분석 중
- 완료
- 실패

완료 시:

- 병명 후보
- 신뢰도
- 분석 요약
- 권장사항
- 재분석 동작

원칙:

- AI는 관찰 저장 후 사용자 요청 시 실행한다.
- AI 결과와 스마트 방제 가이드는 시각적으로 구분한다.
- 근거 또는 상세정보는 필요 시 접기/펼치기로 제공한다.

### 3.6 스마트 방제 가이드 Card

> 과실 상세에서는 본 카드를 표시하지 않는다 (v1.2).

- 카드 제목: **스마트 방제 가이드** (사용자 화면에 "PSIS" 미노출)
- AI 분석 중: 방제 가이드를 준비하고 있습니다.
- AI 분석 완료 안내: AI 분석 결과를 바탕으로 방제 가이드를 제공합니다.
- 결과 제목: 방제 가이드
- 표시 순서:
  1. 보유 농약(재고 우선)
  2. 추천 농약
  3. 사용 방법 (적용 병해충 · 적용 작물 · 희석배수 · 사용 시기 · 안전사용기준 · 주의사항)
- 내부 식별자·API·DB·로그의 `psis` 명칭은 유지한다.

### 3.7 관리 정보 Card

- 기본 접힘 상태
- 관찰번호
- 작성일
- 수정일
- 작성자
- 수정자
- 완료일
- GPS
- Lifecycle
- 삭제 상태
- Version

관리정보는 화면 상단이 아니라 하단에 배치한다.

### 3.8 Bottom Action

- `수정`
- `삭제`

규칙:

- 수정: ODS Primary 또는 승인 시안의 녹색 계열
- 삭제: ODS Danger
- 사진 버튼은 별도로 두지 않는다.
- 삭제 전 복구 불가 안내를 포함한 확인 절차를 유지한다.
- **ODS v1.2:** 1차(원 root) 삭제 시 2차 이상 추적 일괄 삭제 가능 → 건수를 명시한 경고 후 확인.
  2차 이상 삭제는 해당 건만 제거한다.

## 5. 금지사항

- 관찰번호를 상단 제목으로 노출
- 관리정보를 Hero보다 먼저 배치
- 임의의 카드 스타일 생성
- 임의 색상 또는 배지 생성
- 별도 사진관리 버튼 추가
- 표 중심 UI
- 작은 버튼 남발
- 이중 스크롤
- 회색 중심의 무채색 화면
- 승인 이미지보다 정보 계층을 약화하는 변경

## 6. 반응형 및 Android 기준

- 360px 이상 모바일 폭에서 정상 표시
- 텍스트 잘림, 카드 겹침, 버튼 오버플로 금지
- 하단 액션은 Safe Area 반영
- 사진 영역의 터치 타깃 최소 44px
- 뒤로가기, Viewer, Accordion, 수정, 삭제 동작 검증
- Android 실제 기기 또는 에뮬레이터 스크린샷 제출
